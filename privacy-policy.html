WinRecoveryProject Privacy Policy

Effective date: November 22, 2026

This policy applies to WinRecoveryProject for Microsoft Edge, version 0.0.1. The extension provides JSON tools, data conversion, webpage JSON viewing, page translation, and a user-controlled JavaScript setting for the current site.

Information the extension processes

  • Documents and comparison inputs. JSON or text that you enter, paste, or import is saved in Edge extension storage on your device so the extension can restore your work.
  • Query history. The extension stores up to 15 recent query expressions in local Edge extension storage.
  • Preferences and saved queries. Preferences such as display and translation settings, and saved query names and expressions, use Edge extension sync storage. If Edge Sync is enabled for extensions, Microsoft Edge may synchronize this information under your Edge Sync settings and Microsoft's privacy terms.
  • JSON webpages. If you grant the optional permission and enable JSON auto-detection, the extension checks top-level HTTP and HTTPS response information to identify JSON pages and display a viewer. The viewer reads the JSON content of that page. When you choose to open page JSON in the editor, the extension temporarily passes it within the browser session and removes that temporary copy after the editor receives it.
  • Page translation. When you choose translation, or enable its optional automatic setting, the extension reads up to 30,000 characters of visible text from the active HTML page. Translation and source-language detection use Microsoft Edge's on-device APIs. The page text sent to those APIs stays on your device and is not sent to WinRecoveryProject or a cloud translation service. Edge may download a language model the first time a language pair is used.
  • URL import. If you enter a URL in the import feature, the extension requests that address and places the returned text in the editor. The selected website receives that request and handles it under its own policies. Imported text is then saved as editor content on your device.
  • JavaScript setting. If you use the JavaScript control, the extension checks the active page's site and lets you change Edge's JavaScript setting for that site. Edge stores and applies this setting. The site address is used to target the setting; it is not sent to WinRecoveryProject.

How information is used and shared

The extension uses the information above only to provide its user-facing features. WinRecoveryProject does not operate a server that receives your documents, comparison inputs, query history, viewed JSON content, or translation text. The extension does not include analytics or advertising services and does not sell user data.

The extension makes a network request when you explicitly import a URL. Microsoft Edge may synchronize preferences and saved queries if Edge Sync is enabled, and Edge may download the on-device translation model. These services are provided under their respective providers' policies and settings.

Storage and your choices

Editor and comparison content and query history are stored locally by Edge. Query history is limited to the 15 most recent expressions. Preferences and saved queries may be synchronized through Edge Sync. The extension provides controls to clear editor content, remove saved queries, turn JSON auto-detection off, and disable automatic page translation. You can also revoke optional extension permissions in Edge.

WinRecoveryProject is a general-purpose data tool, so content you choose to enter or translate may contain personal information. The extension does not send that content to WinRecoveryProject. Avoid entering passwords or highly sensitive information unless you specifically need to work with it. Anyone with access to your Edge profile or device may be able to access locally stored extension data.

Changes and contact

This policy will be updated if the extension's data practices change. For privacy questions, use the support contact shown on the WinRecoveryProject listing in Microsoft Edge Add-ons. Do not include sensitive personal information in a public support post.
